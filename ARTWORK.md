# Artwork provenance

## Included asset

`assets/frieren_v29_fastfetch_transparent.gif` is the pixel-art animation used
by these Fastfetch configurations.

zxzx generated and iteratively modified the artwork using GPT Astra, starting
from a reference image of Frieren wearing a blue-and-gold head covering and a
pearl earring. The resulting asset changes the rendering style, expression,
colors, background treatment, and presentation, and is supplied as an animation.
It is not a copy of the original image file. Its visual relationship to the
reference is nevertheless acknowledged here.

The character Frieren originates from *Frieren: Beyond Journey's End*.
This collection is an unofficial personal theme project.
